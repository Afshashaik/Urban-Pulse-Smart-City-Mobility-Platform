# Urban Pulse: Smart City Mobility Intelligence Platform

A data analytics project developed as part of the **Infosys Springboard Internship**, focused on understanding urban mobility patterns through the integration of transportation, ride-hailing, bike-sharing, and demographic datasets.

---

## Project Vision

Modern cities generate massive amounts of mobility data every day. This project aims to transform that raw data into meaningful insights that can support better transportation planning, improve commuter experiences, and contribute to smarter urban decision-making.

---

## Problem Statement

City transportation systems often operate using isolated datasets, making it difficult to understand overall mobility patterns. By integrating multiple transportation data sources into a unified analytical platform, this project provides insights that help identify travel trends, service utilization, and opportunities for improving urban mobility.

---

## Project Goals

- Collect and integrate multiple mobility datasets
- Clean and preprocess raw transportation data
- Build a unified analytical dataset
- Perform exploratory data analysis
- Develop interactive Power BI dashboards
- Generate insights to support smart city initiatives

---

## Datasets

| Dataset | Purpose |
|---------|---------|
| Trips | Travel activity analysis |
| Stops | Public transport stop information |
| Stop Times | Transit scheduling analysis |
| Calendar | Service availability |
| Ride Hailing | Ride demand analysis |
| Bike Sharing | Bicycle usage patterns |
| Demographics | Population-based mobility insights |
