# Urban Pulse: Smart City Mobility Intelligence Platform

## Bengaluru Geospatial Mobility Analytics

An end-to-end **data analytics and business intelligence project** developed as part of the **Infosys Springboard Internship**. The project integrates multiple urban mobility datasets and transforms them into interactive Power BI dashboards for analyzing transportation demand, routes, stops, accessibility, mobility patterns, cycling, ride-hailing, weather, and demographic factors.

---

## 📊 Final Power BI Dashboard

The completed Power BI dashboard is included in this repository as:

```text
Urban_Pulse Dashboards final(1).pbix
```

The dashboard contains multiple analytical pages covering different aspects of urban mobility, including:

- Data Acquisition
- Geospatial Mobility Analysis
- Transit Analysis
- Ride-Hailing Analysis
- General Mobility Analysis
- Cycling Analysis
- Forecasting
- Demographic Analysis

### Geospatial Dashboard Highlights

The **Bengaluru Geospatial Mobility Analytics Dashboard** provides an interactive view of selected Origin-Destination (OD) patterns.

Key insights include:

- Total Trips in Selected OD
- Routes in Selected OD
- Stops in Selected OD
- Directions in Selected OD
- Selected OD Service Coverage Map
- Trips by Route
- Stops Covered
- Arrival Time Pattern

Interactive filters allow users to explore data by:

- Route ID
- Direction
- Origin-Destination
- Stop Name
- Date

## 🎯 Project Vision

Modern cities generate massive amounts of mobility data every day. However, transportation data is often distributed across separate systems and datasets.

**Urban Pulse** aims to integrate these datasets into a unified analytical platform that helps identify mobility patterns, transportation demand, service coverage, and opportunities for smarter urban planning.

---

## ❓ Problem Statement

Urban transportation systems generate data from multiple sources such as public transit, ride-hailing services, bike-sharing systems, weather records, and demographic datasets.

Analyzing these datasets independently makes it difficult to understand the complete mobility ecosystem.

This project addresses that challenge by integrating multiple datasets and developing interactive dashboards that support:

- Travel pattern analysis
- Public transport accessibility analysis
- Route and stop analysis
- Ride demand analysis
- Cycling pattern analysis
- Geographic mobility analysis
- Weather and demographic insights

---

## 🎯 Project Objectives

- Collect and integrate multiple urban mobility datasets
- Clean and preprocess raw data
- Build structured analytical datasets
- Perform exploratory data analysis
- Create relationships between fact and dimension tables
- Develop interactive Power BI dashboards
- Generate insights for smart city and transportation planning
